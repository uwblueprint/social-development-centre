# Product context

Product context lives in Notion, the source of truth: [Social Development Centre](https://app.notion.com/p/3db10f3fb1dc815793ebea8f1b44d6cd) (the client, the problem, the team) and its [Product Requirements](https://app.notion.com/p/5c010f3fb1dc8380a8bf8162c46b7dea) database (one PRD per flow, with priority and status). Read the PRD for a feature before building it.
