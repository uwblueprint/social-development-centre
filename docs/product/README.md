# Product context

Product context lives in Notion, the source of truth: [Social Development Centre](https://app.notion.com/p/3db10f3fb1dc815793ebea8f1b44d6cd). Start there for the client, the problem and the current PRDs, and read the PRD for a feature before building it.

Notes from every client meeting with SDC are in [docs/client-meetings](../client-meetings/README.md), newest last. Read them for what SDC asked for and decided, in their own words; the PRDs in Notion are where those decisions turn into scope.
