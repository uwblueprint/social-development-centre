# Outbox

**Outbox** in the sidebar lists every email going out in the next 30 days. Groups, each with its batch count: **Waiting for you**, **Today**, **Tomorrow**, then one per date. Select the arrow at the left of a row to expand it.

## Approve a batch
1. On a batch marked **N to review**, open its **More actions** menu (⋯) and select **Approve all**. The dialog shows the count and when each email sends.
2. Select **Approve all** to confirm.
3. Select **Undo** in the toast (or **Undo (Ns)** on the row) within 1 minute to stop it.

## Send now or don’t send a batch
1. Select ⋯ on the batch row.
2. Choose **Send now** or **Don’t send**, then confirm.

## See who gets an email
1. Select the batch row to expand it.
2. Select a recipient to show their email under their row.
3. Select **Edit for everyone** in ⋯ on the batch row to change every email in the batch.

## Approve, send or remove one email
1. Select the recipient.
2. Select **Approve**. The line beside it says when it sends. **More actions** (⋯) has **Approve and send now**.
3. Select **Don’t send** to remove it. Use **Retry** for a **Couldn’t send** email.

## Edit one email
1. Select the recipient, then **Edit**.
2. Select **Save changes** to save or **Discard** to throw changes away.
3. If other members already have their own edits, choose **Only {name}** or **Everyone**. For everyone, choose **Keep their edits** or **Replace their edits**.
4. Select **Reset to original** to remove an edit.

The email stays paused, with no time limit, until you select **Save changes** or **Discard**. If you leave, the Outbox shows **You have an edit in progress**; select **Open** to go back to it. If someone else has the email open, it shows **{name} has this open**.

**Edited** marks an edited email in the expanded list. **N not sent** at the bottom of a batch lists who didn’t get it and why.
