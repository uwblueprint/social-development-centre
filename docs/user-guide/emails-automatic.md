# Automatic emails (prototype)

Find them under **Automatic emails** in the sidebar. Tabs: **Live**, **Drafts**, **Trash**. Select a row to open it; the **More actions** menu (⋯) holds the rest.

## Create an automatic email
1. Select **New automatic email**. A draft opens.
2. Select the title and type a name.
3. Complete the sentence under the title: **When** (a moment, and a tag for "Tag added to member"), **wait** (**Right away**, **Same day** or **Days after**), **then** (**Send automatically** or **Review each first**) and **to** (**everyone**, or select it and choose **Add condition**; with two or more conditions set **All** or **Any**).
4. Write the subject and message below the sentence.
5. The text next to the buttons says **Saved**, **Saving…** or **Not saved**. If it says **Not saved**, select **Retry**.

## Publish
1. Select **Publish**. If something is missing, the page jumps to it and shows a short red line next to it.
2. Select **Publish** in the confirmation.
- **Preview** shows the email as a member would get it; pick the member at the top. **Send test** is in the ⋯ menu.
- The count after the sentence (for example **12 will get this**) lists who is scheduled.

## Change a live email
1. Open it and select **Unpublish**.
2. Select **Unpublish** in the confirmation. It lists edited emails (with links) only if there are any.
3. Make your changes and select **Publish**.

## Recipients
On a live or trashed email, select **Recipients** at the top: **Member**, **Status**, **Reason**.

## Duplicate, trash, restore
In the ⋯ menu: **Duplicate**, **Move to trash**. In **Trash**: **Restore** (returns it to **Drafts**).

## Leaving with unsaved changes
Selecting a link while the status is not **Saved** asks **Leave without saving?** Choose **Stay and save** to keep working.
