# One-off emails (prototype)

Find them under **One-off emails**. Tabs: **Drafts** and **Sent**.

## Write and send
1. Select **New email**. The draft saves itself; the top bar says **Saved**.
2. Next to **To**, choose **Everyone**, **A group** or **Pick people**.
   - **A group**: select **Add condition**, choose a type, then a value.
   - **Pick people**: select **Add a person** and search by name or email.
3. Write the subject and message.
4. Select **Preview** to see the email as one person, **Send test** to get it in your inbox.
5. Select **Send to N members**, then **Send** in the dialog.

## Check or change who gets it
1. Select the member count next to **To** (for example **14 members**).
2. Select the remove icon on a row to leave that person out of this email.
3. Open **Removed** and select the add icon to bring someone back.
4. Open **Not included** to see who can't get email and why.

## Monthly limit
When a line says **3 members will pass the monthly limit**, select **View** to see them. You can still send.

## Undo or update after sending
For 1 minute after sending, a toast and a line on **Sent** offer **Undo** and **Update email**.
1. **Undo** returns the email to **Drafts**.
2. **Update email** opens it in the Outbox.

## Open, copy or delete
1. Select a row to open it.
2. Select the ⋯ menu on a row, then **Duplicate** (drafts and sent) or **Delete** (drafts).
3. In a draft, the ⋯ menu in the top bar has **Delete draft**.

## See a sent email
1. On **Sent**, select a row.
2. The table shows **Sent**, **Sending** or **Not sent** for each person. Select a person to see their email.
3. Select **Duplicate** to start a new draft from it.

## When something goes wrong
- **Not saved**: select **Retry**.
- The page can't load: select **Try again**.
